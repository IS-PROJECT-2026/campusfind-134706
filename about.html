About CampusFind

Learn how the campus lost and found system works.

What is CampusFind?

CampusFind is a web-based lost-and-found management system designed for university students and staff. It allows users to report lost or found items, browse and search reported items, identify possible matches, and manage the status of their reports.

How It Works

  1. Report — Lost something? Found something? Submit a report with details and optional photo.
  2. Search — Browse the catalogue or search by keywords like "black HP laptop".
  3. Match — CampusFind automatically detects possible matches between lost and found reports.
  4. Recover — Contact the other party and mark items as recovered when returned.

FAQ

Where is my data stored?

All data is stored locally in your browser using localStorage. No server or database is required. Data persists between sessions on the same browser.

How does match detection work?

CampusFind compares lost and found reports based on category, item name keywords, location, and date proximity. When the match score exceeds the threshold, both items are flagged as a possible match.

Can I delete a report?

Yes. Go to My Reports or the item detail page and use the Delete button. Only reports you created can be managed from your session.

Is my contact information public?

Your email is visible on item detail pages so others can contact you about potential matches. Only submit contact details you are comfortable sharing.

Technologies

CampusFind is built with HTML5, CSS3, and vanilla JavaScript. Data persistence uses the browser localStorage API. The project is deployed via GitHub Pages.
